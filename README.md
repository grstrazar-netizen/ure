# Flowtime PWA Prototype

Clickable mobile-first prototype for a voice-driven time tracking app, built with Bulma CSS.

## Prototype includes

- Day-by-day paper card layout inspired by your sketch
- Swipe left/right to move between days
- Daily activity lines with task, duration, and amount
- Voice capture modal
- AI parsing confirmation modal
- PDF preview modal and download placeholder action

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.
